# Voz Clara Landing

Prompt inicial (estrutura geral):

Crie uma landing page institucional para uma clínica de fonoaudiologia, em português do Brasil, com design clean, acolhedor e profissional (paleta em tons de azul/verde suaves, tipografia arredondada). Estrutura de seções: Hero (nome da profissional, foto, chamada para agendamento), Sobre a profissional, Serviços, Perguntas Frequentes, Depoimentos, Blog (grade de posts, sem funcionalidade ainda), Contato, Rodapé com redes sociais. Site responsivo, mobile-first, sem login nem sistema de agendamento nesta etapa — apenas apresentação e captação de contato via WhatsApp e formulário.
